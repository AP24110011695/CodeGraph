# Portfolio Site Description

## Headline

CodeGraph — The AI Software Architect for Every Codebase

## Subhead

A production-minded FastAPI platform that turns repositories into architectural intelligence: graphs, memory, multi-agent planning, impact prediction, and Copilot Q&A.

## Body

Most “AI for code” demos stop at search. CodeGraph goes further. It models structure (parsers, dependency and knowledge graphs), keeps durable summaries (Repository Memory), retrieves context (Semantic + RAG), reasons about architecture, plans work across specialist agents, and predicts the blast radius of a change. A Unified Copilot orchestrates these engines through a Planning Engine so new capabilities plug in as tools — without duplicating business logic.

RC-1 ships with a green automated suite, OpenAPI docs, and an explicit production-debt register (auth, Redis, live VCS) — honesty suitable for real engineering portfolios.

# ATS-Ready Project Description

**CodeGraph — AI Software Architecture Platform (Python / FastAPI)**

Built an enterprise-style repository intelligence platform that analyzes uploaded codebases, constructs dependency and knowledge graphs, maintains structured repository memory, and answers architecture questions through a planning-driven multi-agent Copilot. Implemented modular engines for semantic retrieval (RAG), architecture reasoning, timeline evolution, change-impact prediction, and composed engineering reports behind a thin FastAPI layer with Pydantic contracts, cache/telemetry facades, and a 1,200+ test regression suite (RC-1 green). Emphasized composition over duplication: new capabilities orchestrate existing engines rather than reimplementing indexing, graph traversal, or business logic.

# Recruiter-Friendly Summary

**Project:** CodeGraph  
**Role fit:** Backend Engineer, Platform Engineer, AI/ML Engineer (applied), Full-Stack (backend-heavy)  
**Stage:** Open-source Release Candidate (`1.0.0-rc.1`)

**In one sentence:**  
A Python/FastAPI platform that analyzes software repositories and answers architecture questions using knowledge graphs, repository memory, multi-agent planning, and impact analysis.

**What was built:** End-to-end backend intelligence (upload → analyze → remember → plan → answer), not just a notebook prototype.

**Proof of quality:** 1,200+ automated tests passing; modular engines; documented tech debt; CI workflow; MIT license.

**Not claiming:** Full multi-tenant SaaS with live GitHub OAuth — mocks and stubs are labeled for honesty.

**Ask in interview:** “Walk me through how Copilot decides which engines to call” or “How did you avoid duplicating graph traversal?”

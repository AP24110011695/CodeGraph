# LinkedIn Project Description

**CodeGraph | AI Software Architecture Platform | Python, FastAPI**

I built CodeGraph to answer a hard engineering problem: repositories are large, tribal knowledge is scattered, and “what breaks if I change this?” is expensive to answer manually.

CodeGraph ingests a codebase, builds dependency and knowledge graphs, maintains structured repository memory, and uses a planning-driven multi-agent Copilot to answer architecture questions. It also predicts change impact, tracks evolutionary hotspots, and generates composed engineering reports — all by **composing** specialized engines rather than rewriting analyzers.

**Highlights**

- FastAPI intelligence platform with 50+ domain modules  
- Planning → Agents → Engines orchestration (Copilot CG-070)  
- Impact analysis + timeline intelligence on shared graph/memory foundations  
- RC-1 green regression suite (1220+ tests)  
- Living AI_CONTEXT docs for maintainable AI-assisted development  

**Stack:** Python, FastAPI, Pydantic, pytest, tree-sitter, RAG/embeddings abstractions, CacheInterface, telemetry middleware.
